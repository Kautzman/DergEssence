# DergEssence

A World of Warcraft addon for Evokers to track essence.

## Description

DergEssence is a WoW addon designed specifically for Evoker class players to help track and manage their essence resource more effectively.

## Features

- Essence tracking for Evoker class
- Slash commands for easy configuration
- Persistent settings across sessions

## Installation

1. Download the latest release
2. Extract the `DergEssence` folder to your WoW AddOns directory:
   - Windows: `C:\Program Files (x86)\World of Warcraft\_retail_\Interface\AddOns\`
   - Mac: `/Applications/World of Warcraft/_retail_/Interface/AddOns/`
3. Restart WoW or reload your UI with `/reload`

## Usage

### Slash Commands

- `/dergessence` or `/de` - Display addon information and available commands
- `/dergessence toggle` or `/de toggle` - Enable or disable the addon

## Requirements

- World of Warcraft 12.0.1 or higher
- Evoker class character
